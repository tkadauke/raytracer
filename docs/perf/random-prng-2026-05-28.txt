Command:

  ./build/benchmark/benchmarks/benchmarks --benchmark_filter='bm_(random|legacy_rand|mt19937)' --benchmark_min_time=0.1s

Notes:

  Benchmarked on the Syrus Linux worker after a clean benchmark build. The
  machine still reported background load, so compare CPU time, not wall time.
  The benchmark source includes three choices:

  - bm_random_*: project Number::random, thread-local PCG32
  - bm_legacy_rand_*: legacy std::rand baseline
  - bm_mt19937_*: thread-local std::mt19937_64 candidate

Summary:

  PCG32 is about 9.8x faster than the legacy std::rand single-thread baseline
  for random doubles (1.55 ns vs 15.2 ns CPU). It is about 4.1x faster than the
  thread-local mt19937_64 candidate (1.55 ns vs 6.39 ns CPU). Under the 8-thread
  benchmark, PCG32 stays near 1.74 ns CPU per call while std::rand rises to
  152 ns CPU per call, an 87x CPU-time improvement and evidence that removing
  the shared std::rand state matters for concurrent render workloads.
